# 硬橙控 发行说明

## Alpha-0.1.0

**发布日期**：2026-11-01
**更新内容**：第一个版本——梦开始的地方

这是「硬橙控」的第一个公开版本。感谢你见证它梦开始的地方。

### ✨ 新功能

- **托盘电量显示**
  - 每台蓝牙 / 2.4G 设备在系统托盘显示一个电量数字图标，颜色随电量变化（≥80 绿色 / ≥50 黄色 / <30 红色）
  - 低电量自动弹窗提醒，可对单台设备单独设置
  - 总控托盘：左键打开主面板，右键管理所有设备

- **设备识别**
  - 支持蓝牙经典设备与 BLE（GATT）设备电量读取
  - 支持 2.4G 无线接收器：自动识别接收器下挂的鼠标 / 键盘并归组显示
  - 内置多家厂商私有电量协议解析
  - 扫描窗口卡片式设备列表，一键加入设备库

- **本地外设管理器**
  - 系统默认声音输出一键切换（耳机 ↔ 扬声器）
  - 笔记本内置键盘「代码模式」「游戏用英文」快捷开关

- **其他**
  - 开机自启动
  - 全局热键
  - 单实例运行保护（重复启动自动唤起已有窗口）

### 📥 安装

1. 下载 `HardOrwareCtrl 0.1.0.zip` 并解压到任意目录
2. 双击 `硬橙控.exe` 运行
3. 如需开机自启，在设置中开启

### ⚠️ 已知限制

- 仅支持 Windows 10 1809 及以上版本
- 部分设备私有协议未覆盖时可能显示「无电量」
- Alpha 阶段，UI 与功能仍在快速迭代
